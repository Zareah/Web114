JavaScript Questions

1. Why is textContent safer than innerHTML?

Answer: It denies any alterations when others visit, use or midify the site. textContent is like a more pemanent and high security type of text.

2. How are HTML elements connected to JavaScript variables using DOM selection?

Answer: We group the elements by their IDs (which we name) to create variables that reference them in JavaScript.

3. What would happen to the text box with id="text" if I added this line to the code above it:

text.textContent = "Hello!"

Answer: It would change any and all messages within the "text" id to the new message. Then the new message would be seen on the screen.
